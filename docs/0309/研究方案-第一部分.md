# 第一部分 研究方案
## ——要做什么、为什么做、打算怎么做

**项目名称：** 三餐管家  
**组别：** 小学高  
**项目类别：** 社会科学

## 1. 要做什么

我想做一个小应用，名字叫**三餐管家**。因为我奶奶手术后，家里每天都会遇到吃什么、怎么吃、药怎么记这些问题。我就想先做一个“够用、好用”的版本，先帮家里把最头疼的事解决掉。

### 1.1 我的目标
1. 让我奶奶不用打字，直接说话就能记下来；
2. 让我和家人拍一下医嘱和药盒，就能看到重点；
3. 让系统告诉我们下一顿大概怎么吃更合适。

### 1.2 我希望做出的成果
- 一个能跑起来、能演示的小 App；
- 一套我家真的能用的流程（我奶奶说，我和家人拍、看）；

### 1.3 我最想先解决的真实场景
- **早饭前**：我奶奶说“今天早上吃了什么、血压多少”，系统自动记下来；
- **做饭前**：我和家人拍医嘱或药盒，系统提醒今天要注意什么；
- **备菜时**：系统告诉我们哪些食材更合适，哪些要少吃；
- **饭后**：我们能快速回看当天记录，判断执行得好不好。

---

## 2. 为什么做

### 2.1 这个问题来自哪里
我奶奶手术后，医生说要低脂、少盐、少糖，还要按时吃药。听起来很清楚，但真到了每天做饭的时候，我们还是会犹豫：这个能不能吃？吃多少？

### 2.2 平时最麻烦的地方
- 药名和说明太复杂，不容易一下看懂；
- 只记住“少油少盐”还不够，不知道每顿到底吃什么；
- 医嘱放久了容易忘，执行会断断续续。

有时候家里人想法还不一样：有人觉得“吃一点没事”，有人觉得“还是别吃”。这样就会来回讨论，做饭也会变慢。

### 2.3 这个研究有什么价值
1. **对我家有用**：做饭的时候不那么慌，心里更有数；
2. **对我有用**：我学会了不只是想办法，还能把办法做出来；
3. **对别人也可能有用**：以后也许能帮到别的家庭。

---

## 3. 打算怎么做

### 3.1 我的做法
按“先能用、再变好”的思路来做：
我先把最基本的功能做出来，能用起来以后再慢慢改。

### 3.2 三个核心功能
- **语音记录**：我奶奶说一句话，系统自动记下来；
- **拍照识别**：拍医嘱和药盒，系统提取重点规则；
- **智能建议**：结合当天记录，给下一餐建议。

### 3.3 研究步骤
1. 先把家里每天的麻烦记下来；
2. 想办法把这些麻烦变成 App 功能；
3. 在家里试着用，看哪里别扭；
4. 再一点点改好。

### 3.4 我会怎么判断有没有效果
- 看有没有更容易坚持记录；
- 看做饭时是不是更快决定吃什么；
- 看我奶奶愿不愿意继续用，是不是对系统产生依赖。

### 3.5 可行性说明
- 现在的技术能做到语音和拍照识别；
- 我家就是现成的使用场景；
- 我可以分步骤做，不用一次做太多；
- 这个工具只是帮忙提醒，不能代替医生。

---

## 4. 本部分结论

这个项目就是从我家真实问题里长出来的。现在看，方向是对的，也确实有用。我会继续把它做得更顺手一些。
