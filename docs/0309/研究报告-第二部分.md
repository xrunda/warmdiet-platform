# 第二部分 研究报告
## ——做了什么、怎么做的、发现了什么、结论是什么

**项目名称：** 三餐管家  
**组别：** 小学高  
**项目类别：** 社会科学

## 1. 做了什么（研究实施内容）

这段时间，我围绕家里术后照护的真实情况，完成了“三餐管家”的原型设计和实践。主要做了下面几件事：

1. **构建语音记录能力**  
   让老人不用打字，只要说一句话，就能记录每天吃了什么、身体情况怎么样。这里调用的是语义理解大模型，通过提示词提取语音中的关键信息并进行记录保存。这部分我应接入了大模型，但是还没有和小爱同学打通，因为这个能力需要小爱同学官方审核，目前正在审核阶段。

2. **构建拍照识别能力**  
   家里人拍一下医嘱和药盒，系统就能提取重点，比如“少油、少盐、少糖”。这里利用的是多模态大模型的图片理解能力，可以理解图片上的文字，也可以理解图片本身的含义。为下一步内容分析做准备，这部分已经实现了。

3. **构建饮食建议能力**  
   系统会根据当天记录和系统保存的医嘱，给出下一餐建议，比如推荐吃什么、少吃什么，怎么吃。这部分的能力是大语言模型自身的能力。

4. **构建家庭协作流程**  
   我们慢慢形成了一个简单分工：老人负责说，家人负责拍，系统负责记和提醒。

5. **完成多页面应用原型展示**  
   我把 App 页面做成了可演示版本，能完整走通“记录—识别—建议”流程。

## 2. 怎么做的（研究过程与方法）

我采用的是 **Vibe Coding（氛围编程）** 方法：先把需求讲清楚，再快速做出原型，然后边用边改。这里使用了多个模型，包括豆包、DeepSeek、kimi 等等，每个模型有自己擅长的方向和能力，要懂得利用模型的长处为自己工作，学会指挥模型干活。

### 2.1 过程步骤

**步骤一：问题拆解**  
先从家里每天遇到的问题出发：
- 记录难（老人输入困难）；
- 理解难（医嘱和药品信息复杂）；
- 执行难（每餐难以判断是否合规）。

**步骤二：功能映射**  
把问题对应成功能：
- 记录难 → 语音记录；
- 理解难 → 拍照识别；
- 执行难 → 智能建议。

**步骤三：原型实现**  
先把核心流程做出来：
- 语音输入并结构化保存；
- 图片信息提取并更新规则；
- 结合规则与记录生成建议输出。

**步骤四：家庭场景验证**  
在家里反复试用，重点看三件事：会不会用、看不看得懂、做不做得到。

### 2.2 分工机制
- **我**：负责想法、流程设计和测试记录；
- **爸爸**：负责技术调试和环境支持；
- **老师**：负责方法指导，帮我把研究逻辑理顺。

## 3. 发现了什么（研究发现与分析）

### 3.1 核心发现

1. **语音是奶奶可持续使用的关键入口**  
   奶奶更愿意说话记录，不太愿意打字，所以语音入口很重要。

2. **“拍照识别”能显著降低医嘱理解成本**  
   医嘱内容变成简明规则后，家里人更容易达成一致，不会各说各的。

3. **建议必须“具体到一餐”才有执行力**  
   只说“少油少盐”太笼统，必须具体到“这顿吃什么、少吃什么”才有用。

4. **家庭协作比单点功能更重要**  
   项目的价值不只是功能本身，更是让一家人配合得更顺畅。

### 3.2 过程中暴露的问题
- 方言、口语化表达可能影响识别准确性；
- 医嘱描述存在差异，规则提取需进一步标准化；
- 提醒方式仍有优化空间（频率、时机、表达方式）。

### 3.3 阶段性成效
- 原型已形成“记录—识别—建议”闭环；
- 家庭成员对流程理解更一致，日常执行更有依据；
- 项目从“想法”走向“可展示、可复用”的实践成果。
- 正在对接智能音箱的语音输入能力（需要等待平台审核应用）
---

## 4. 结论是什么（研究结论与价值）

### 4.1 研究结论
这次实践说明：在术后家庭照护场景里，把语音记录、拍照识别和饮食建议结合起来，确实能让日常管理更容易执行，也更连续。

### 4.2 成果价值
1. **家庭应用价值**：把抽象医嘱变成每餐可执行建议；
2. **方法价值**：证明“从真实问题出发，再边做边改”是有效的；
3. **学习价值**：让我深刻体会到人工智能时代的到来，对我们学习生活带来的改变是巨大的；
4. **推广价值**：未来可用于更多术后或慢病家庭。

### 4.3 后续优化方向（与结论衔接）
- 设计医生角色进入系统，更好的对慢性病老人居家健康管理起到关键作用；
- 补充术后饮食知识库和菜谱库；
- 优化提醒机制与家庭协同反馈闭环。
- 增加应用上架市场的产品设想，让更多有需要的家庭受益。
- 下一步准备在百度智能屏上接入应用，给应用设计一个虚拟的人物形象，这样在对话的时候，奶奶可以看到一个虚拟的人物形象和他交流，会更有意思。
